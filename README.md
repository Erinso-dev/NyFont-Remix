## 📌 二改新增内容

### 1. 字体标签分类（新增 `nytwTags.js`）
- 每个字体可以挂**多个标签**，标签可自定义名称与颜色（10 色循环）
- **标签管理**面板：新建 / 改名 / 换色 / 删除（删标签不删字体）
- 字体库顶部**按标签筛选**，可折叠，标题旁会显示当前生效的标签
- 字体库**搜索框**：按字体名、文件名、格式、标签名实时搜索
- 排序：默认 / 按名称 / 按标签；显示「显示 N / 共 M 个字体」
- 列表每行显示所属标签，点标签直接筛选；右侧 🏷 按钮可勾选标签
- 字体选择弹层顶部也有标签筛选，字体行显示标签

### 2. 批量管理
- 「多选」模式：逐条勾选，支持用搜索/标签筛选先缩小范围
- **批量打标签**：添加 / 移除 / 替换为
- **批量删除**：勾选后一次删除，带二次确认，会同时清理字体文件与失效的字体引用

### 3. 阅读样式增强
- **左右边距分别设置**：不再依赖居中收窄，美化自带不对称留白时可直接补偿
- **两端对齐**：`text-align: justify` + `text-justify: inter-ideograph`
- **每行独立成段（逐行首行缩进）**：把单个换行包成块级元素，让首行缩进逐行生效；关闭时会完整还原 DOM
- **美化绑定**：把当前整套阅读样式绑定到当前主题，切换美化时自动套用
- **结构诊断**：列出最后一条消息的 DOM 结构，便于排查排版问题

### 4. 界面与易用性修复
- 字体库改为**列表独立滚动**，工具栏、标签筛选、批量操作栏固定不动（类似冻结窗格）
- 修复点击标签时酒馆扩展面板被收起
- 修复编辑消息时 `.mes_text` 的缩进把编辑按钮推歪
- 修复下拉框、勾选框隐藏元素占位导致开关跑偏
- 浅色/深色美化下文字自动取反，避免白字白底看不清（不依赖主题变量）
- 数字输入框与下拉框的尺寸、字体、对齐统一

## 📦 安装

酒馆 → 扩展 → 安装扩展程序 → 填入本仓库地址：

```
https://github.com/Erinso-dev/NyFont-Remix
```

或把本文件夹放进 `public/scripts/extensions/third-party/` 后重启酒馆。

## 💾 数据兼容

- 设置键仍然是 `Ny-font-manager`，**从原版升级过来字体、标签、阅读样式都不会丢**
- 扩展目录名会按实际安装位置自动识别，所以仓库可以起任意名字
- 「导出字体配置」会把标签一起导出，换设备导入即可恢复

## ✨ 原版已有的主要功能

（以下为原作者实现，本二改版完整保留）

- 全局 / 正文 / 独立对话 / 自定义包裹字体
- **多语言字体混排**：为汉字、假名、韩文、拉丁、数字等分别指定字体
- Web 字体（CSS 链接）导入、本地字体文件上传（存 IndexedDB）
- 字体配置导入导出（含本地字体文件）
- 分层阅读样式：整体 / 正文 / 对话的字号、字距、行高、颜色、段距、缩进、字重、倾斜
- 阅读样式预设的保存、导出、导入
- 外部聊天字体自动导入修复（解决角色卡 / 正则里的字体被过滤）
- 流式渲染模式与动画（打字机 / 模糊显现 / 流光浮现、光标设置）
- 长期文字动画（呼吸微光、边缘辉光、流光扫过、墨迹浮动等）

## ⚠️ 注意事项

- 字体文件存在浏览器本地（IndexedDB），换浏览器或清数据前请先导出字体配置
- 超大字体（>20MB）首次加载会偏慢，建议用裁剪过的 WOFF2
- 「每行独立成段」会改动消息 DOM，遇到美化冲突时可随时关闭，关闭即还原
