# Ny 字体管理器（二改版）

给 SillyTavern 用的字体与阅读排版管理扩展。

在原版「Ny 字体管理器」基础上做了二改，主要增加了**字体分类管理**和**阅读排版的精细控制**，界面改成玻璃质感，并自动适配浅色/深色美化。

- 原作者：Ny
- 二改：Erinso-dev
- 许可证：GPL-3.0

---

## 安装

在酒馆的「扩展程序 → 安装扩展」里填：

```
https://github.com/Erinso-dev/NyFont-Remix
```

装完刷新页面，在扩展列表里展开「Ny字体管理器（二改版）」即可。

> 扩展文件夹叫什么名字都可以，设置项存在 `Ny-font-manager` 这个固定键下，
> 所以改名、重装都不会丢配置。

## 一、字体设置

### 字体覆盖

可以分别指定三种字体：

| 位置 | 作用范围 |
|---|---|
| 全局字体 | 界面和正文 |
| 正文字体 | 正文内容 |
| 对话字体 | 引号里的对话 |

点字体输入框会弹出**带搜索的选择框**：滚到哪个字体，哪一行的名字就用该字体自己的字形显示。

选择框里分四个分组：

- 通用 (System)
- 中文字体 (Chinese)
- 英文/其他 (English/Other)
- 导入字体 (Imported)

前两组是系统内置字体，默认折叠，点标题展开。

### 按语言设置字体

可以给不同字符范围单独指定字体，例如汉字用 A 字体、日文假名用 B 字体、数字用 C 字体。规则可以添加多条。

### 自定义包裹字符字体

用一对符号把文字包起来，让这段文字使用指定字体，例如 `『这段文字』`。

支持**多条规则**：每条规则独立选字体、独立设定符号，不同规则互不影响。

## 二、显示设置

### 阅读样式

「阅读样式」是整套正文排版的总开关，下面分几个子项：

#### 字号 / 字距 / 行高

整体、正文、对话三级，留空表示继承美化本身的值。

#### 颜色

正文颜色、对话颜色、斜体颜色等。

#### 字体样式

字重和斜体。

注意：多数中文字体只有「常规 / 粗体」两档字重，所以选「偏细(300)」「中等(500)」看起来会和「正常(400)」一样，这是字体本身的限制，不是设置没生效。

#### 段落 / 缩进

- **段距**：段与段之间的空隙
- **缩进**：首行缩进，可分整体 / 正文 / 对话
- **每行独立成段**：把单个换行也当成一个段落，这样首行缩进才能逐行生效
- **查看正文结构**：把最后一条消息的 DOM 结构列出来，便于排查缩进不生效的原因

#### 缩进只作用于指定标签内

有些美化的消息里，正文被 `<content>` 这类标签包着，标签外面还有时间栏、状态栏之类的文字。这些地方通常不需要首行缩进。

勾选后填写标签名（如 `content`），规则是：

- 只有被这些标签**包住**的段落才缩进
- 标签外面的一律不缩进
- 可以填多个标签，用逗号或空格隔开，命中任意一个即生效
- 标签里再套别的标签，内层也算在范围内

匹配方式有两种：

| 方式 | 含义 |
|---|---|
| 只在这些标签内缩进 | 白名单：列表内的缩进，其余不缩进 |
| 除了这些标签都缩进 | 黑名单：列表内的不缩进，其余照常缩进 |

输入框会记住你用过的标签，下次点开会弹出候选。

这一组设置可以**保存到当前酒馆预设**：切换预设时，如果勾了「自动套用」，会自动换成该预设保存的标签设置。

#### 宽度 / 对齐

- **正文宽度**：以字符为单位（ch）限制每行的宽度，留空表示跟随美化
- **左微调 / 右微调**：正值让正文往里收（变窄），负值往外扩（变宽），左右互不影响，用来补偿美化本身的不对称留白
- **两端对齐**：让正文左右边缘齐平

#### 预设

可以把手上的排版存成**阅读样式预设**，方便在不同美化之间切换：

- 保存新预设 / 保存修改 / 应用 / 删除
- 导入 / 导出（`json`）
- 可选「包含字体设置」「导出时包含 Web 字体」

预设里的排版和字体是分开存的，不包含本地字体文件本身。

#### 美化绑定

把**当前整套阅读样式**绑定到**当前美化**：

- 切换美化时，如果该美化有绑定，会自动套用
- 如果该美化没有绑定，会重置为「全部继承」，并弹出 **12 秒可撤销**的提示条

#### 文字动画与流式输出

原版功能，包括流式输出的渲染模式、逐字动画、光标样式等。

## 三、导入字体

- 导入本地字体文件（ttf / otf 等）
- 搜索字体名称、文件名、标签
- 排序、多选、批量打标签、批量删除
- 标签系统：新建标签、给字体打标签、按标签筛选
- 标签筛选栏可以折叠，字体列表独立滚动，上方工具条固定不动

---

## 四、界面外观

- 面板为玻璃质感（半透明 + 背景模糊），底层是美化的背景
- 文字颜色会根据面板背后的实际底色自动切换深色/浅色，保证在浅色美化下也看得清
- 字体选择弹层宽度跟随设置面板，不会被裁切

---

## 五、使用说明

- 所有「留空」的输入框都表示**继承美化本身**的效果，不是设成默认值
- 改完设置不需要手动保存，会自动保存
- 如果某项设置看不到效果，先看「查看正文结构」，确认目标元素是不是被美化的结构挡住了
