# Ny 字体管理器（二改版）

SillyTavern 的字体与阅读排版扩展，基于原版「Ny 字体管理器」二次修改。

**本 README 只介绍二改的部分。** 原版已有的功能（字体覆盖、字号/字距/行高、颜色、字重、按语言设置字体、自定义包裹字符、导入字体、文字动画、流式输出渲染等）保持原样，这里不再展开。

- 原作者：Ny
- 二改：Erinso-dev
- 许可证：GPL-3.0

---

## 安装

在「扩展程序 → 安装扩展」里填：

```
https://github.com/Erinso-dev/NyFont-Remix
```

装完刷新页面即可。

扩展文件夹叫什么名字都可以，设置存在 `Ny-font-manager` 这个固定键下，改名或重装都不会丢配置。

## 二改内容

### 1. 字体库：标签与批量管理

导入的字体可能很多，所以加了分类能力：

- **标签系统**：可以新建自己的标签（名称 + 颜色），给字体打多个标签
- **标签筛选栏**：按标签过滤，显示每个标签下的字体数量；这个筛选栏可以折叠，不占地方
- **搜索**：按字体名、文件名、标签搜索
- **排序**：多种排序方式
- **批量操作**：多选后可以批量打标签、批量删除
- **冻结工具条**：搜索、排序、标签栏固定在顶部，只有字体列表独立滚动，滑到列表底部也能随时改筛选条件

### 2. 字体预览

字体列表里，每一行的名字会用**该字体自己的字形**显示。

字体文件存在浏览器本地数据库里，体积可能很大，所以预览是**滚动到可见时才加载**的，不会一次性加载几十个字体。加载过的字体不会重复加载。

字体选择弹层（点字体输入框出来的那个）同样有预览，并且：

- 弹层宽度跟随设置面板，不会被裁切
- 内置字体分组（通用、中文字体）默认折叠，点标题展开
- 点输入框不会弹出键盘，因为它只是用来选的

### 3. 自定义包裹字符：支持多条规则

原版只能设置一组「字体 + 一对符号」。二改后可以添加多条规则：

```
独立字体  [ 宋体 ]  符号 [ 『 ] → [ 』 ]
独立字体  [ 黑体 ]  符号 [ 〔 ] → [ 〕 ]
```

每条规则的字体和符号互相独立，文字要紧挨着符号并成对出现才生效。

### 4. 段落 / 缩进

- **段距**、**首行缩进**：可分整体 / 正文 / 对话三级
- **每行独立成段**：把单个换行也当作段落，这样首行缩进才能逐行生效
- **查看正文结构**：列出最后一条消息的 DOM 结构，缩进不生效时可以靠它定位原因

### 5. 缩进只作用于指定标签内

有些美化的消息里，正文被 `<content>` 这类标签包裹，标签外面还有时间栏、状态栏。这些地方通常不需要首行缩进。

勾选后填写标签名，规则是：

- 只有被这些标签**包住**的段落才有首行缩进
- 标签外面的一律不缩进
- 可以填多个标签，用逗号或空格分隔，命中任意一个即生效
- 标签里再嵌套别的标签时，内层也算在范围内

匹配方式二选一：

| 方式 | 含义 |
|---|---|
| 只在这些标签内缩进 | 白名单：列表里才缩进，其余不缩进 |
| 除了这些标签都缩进 | 黑名单：列表里不缩进，其余照常缩进 |

输入框会记住用过的标签，下次点开有候选。

这一组设置可以**保存到当前酒馆预设**：不同性质的酒馆预设对包裹正文的标签往往不同，勾上「切换酒馆预设时自动套用」后，换预设会自动换成对应的一套。

### 6. 宽度 / 对齐

用来控制正文在气泡里的横向位置和宽度：

- **正文宽度**：以字符为单位（ch）限制每行宽度，留空表示跟随美化
- **左微调 / 右微调**：正值往里收（变窄），负值往外扩（变宽），左右互不影响
- **两端对齐**：让正文左右边缘齐平

**建议的调整顺序**（从影响最大的开始）：

1. **先调正文宽度** —— 它决定每行在哪里换行，观感差别最大
2. **再开两端对齐** —— 让右边缘齐平
3. **最后用左右微调收尾** —— 如果还有偏差（比如美化左边有头像/竖线导致正文偏右，或者两端对齐后仍不齐），再用左右微调分别补偿

顺序反了容易白调：宽度没定好时，边距怎么调都会随换行变化。

### 7. 阅读样式预设

把当前排版存成预设，方便在不同美化之间切换：

- 保存新预设 / 保存修改 / 应用 / 删除
- 导入 / 导出（json）
- 可选「包含字体设置」「导出时包含 Web 字体」

缩进范围那三项（开关、标签、匹配方式）会随预设一起保存和恢复。

### 8. 美化绑定

把**整套阅读样式**绑定到**当前美化**：

- 切换到有绑定的美化时，自动套用
- 切换到没有绑定的美化时，重置为「全部继承」，并弹出**停留 12 秒的撤销提示**，避免手误清空后无法回头

> 注意区分：**美化绑定**存的是整套排版；**缩进范围**是单独绑定到**酒馆预设**的，两者互不影响。

### 9. 界面

- 面板改为**玻璃质感**（半透明 + 背景模糊），透出美化自己的背景
- 文字颜色根据面板背后的实际底色**自动切换深色/浅色**，浅色美化下也不会看不清
- 开关、输入框、按钮的尺寸和间距做了统一，避免和美化原有样式打架

## 原版已有功能

以下都是原作者的功能，本二改未改动逻辑，只是外观随之适配：

- 全局 / 正文 / 对话字体覆盖
- 字号、字距、行高
- 文字颜色、斜体颜色
- 字重、斜体
- 高级范围（自定义元素选择器）
- 按语言设置字体
- 导入字体（ttf / otf 等）
- 文字动画、流式输出渲染模式

## 已知限制

- 多数中文字体只有「常规 / 粗体」两档字重，选「偏细(300)」「中等(500)」看起来会和「正常(400)」一样，这是字体本身的限制，不是设置没生效
- 字体预览依赖字体文件本身，网络字体需要联网
- 首行缩进要逐行生效，需要打开「每行独立成段」；如果美化已经把每行渲染成独立段落，这个开关不会有变化
